# CMIP6 한국 기후 재현성 평가

본 프로젝트는 CMIP6 기후모델이 1995년부터 2014년까지 한국의 기온과 강수 특성을 얼마나 잘 재현하는지 평가하기 위해 수행되었다.

분석 변수는 2 m 기온(tas)과 강수량(pr)이다. 기준자료로는 ERA5 재분석자료를 사용하였고, 최종 검증자료로는 기상청 ASOS 월자료를 사용하였다.

## 1. 연구 목적

CMIP6 자료는 미래 기후 전망에 널리 사용되지만, 특정 지역에 적용하기 전에는 해당 지역의 현재 기후를 얼마나 잘 재현하는지 먼저 확인할 필요가 있다. 본 연구에서는 한국 주변 영역을 대상으로 CMIP6 모델의 기온과 강수 재현성을 평가하였다.

특히 한국은 계절 변화가 뚜렷하고 여름철 강수 집중성이 강하기 때문에, 기온뿐 아니라 강수 재현성을 함께 확인하는 것이 중요하다.

## 2. 분석 기간

분석 기간은 1995년부터 2014년까지로 설정하였다.

이 기간은 CMIP6 historical 실험의 후반부에 해당하며, 20년 월자료를 이용하면 단일 연도의 변동성을 줄이고 월별 기후값과 계절성을 비교하기에 적절하다고 판단하였다.

## 3. 분석 영역

초기 분석 영역은 한국을 포함하는 사각 영역으로 설정하였다.

위도 범위: 33–39°N
경도 범위: 124–132°E

이 영역은 남한과 주변 해역을 포함한다. 서로 다른 해상도를 가진 CMIP6 모델들을 같은 조건에서 비교하기 위해 먼저 사각 영역 평균을 사용하였다.

다만 이 영역에는 서해, 남해, 동해 등 해양 격자가 포함되므로, 이후 ERA5에 South Korea land mask를 적용하여 사각 영역 평균과 남한 육지 평균의 차이도 확인하였다.

## 4. 사용 자료

### ERA5

ERA5는 CMIP6 모델과 격자 기반으로 비교하기 위한 기준자료로 사용하였다. ERA5는 공간적으로 연속적인 기후장을 제공하기 때문에 CMIP6 모델 평가에 적합하다.

사용 변수는 2 m temperature와 total precipitation이다. 기온은 Kelvin에서 Celsius로 변환하였고, 강수는 mm/day 단위로 맞추었다.

### CMIP6

분석에 사용한 CMIP6 historical 모델은 다음과 같다.

- MPI-ESM1-2-LR
- MPI-ESM1-2-HR
- ACCESS-CM2
- CanESM5

CMIP6 자료는 모델별 해상도가 서로 다르다. 따라서 모델 평가 시 CMIP6를 ERA5 고해상도 격자로 올리지 않고, ERA5를 각 CMIP6 모델의 고유 격자로 보간하였다. 이 방식은 저해상도 모델의 해상도를 인위적으로 높이지 않기 위한 처리 방식이다.

CMIP6 변수 처리 방식은 다음과 같다.

tas: Kelvin에서 Celsius로 변환
pr: kg m-2 s-1에서 mm/day로 변환

### ASOS 관측자료

최종 검증자료로 기상청 ASOS 월자료를 사용하였다. 대표 지점은 다음 7개이다.

- 강릉
- 서울
- 대전
- 대구
- 광주
- 부산
- 제주

ASOS 월합강수량은 월별 일수로 나누어 mm/day 단위로 변환하였다. 이는 ERA5 및 CMIP6 강수 단위와 일관되게 비교하기 위한 처리이다.

## 5. 분석 흐름

본 프로젝트는 단계적으로 진행하였다.

Phase 1: 연구 주제 설정 및 분석 방향 수립
Phase 2: ERA5 자료 확보 및 구조 확인
Phase 3: CMIP6 자료 테스트 다운로드 및 구조 확인
Phase 4: CMIP6 전체 기간 자료 전처리
Phase 5: ERA5와 CMIP6 기본 EDA
Phase 6: 기준기후 월별 climatology 분석
Phase 7: ERA5 기준 CMIP6 모델 평가
Phase 8: 여름철 및 극한기후 proxy 분석
Phase 9: CMIP6 모델 수 확장
Phase 9-B: MPI-ESM1-2-HR을 이용한 해상도 확장 비교
Phase 10: ERA5 South Korea land mask 분석
Phase 10.5: CMIP6 land mask 보조분석
Phase 11: ASOS 관측자료 기반 검증
Phase 12: 전체 결과 통합 및 최종 결론 정리

## 6. 주요 결과

ASOS 7개 지점 평균을 최종 관측 기준으로 사용한 결과, 기온은 CMIP6 모델들이 비교적 안정적으로 재현하였다. 특히 MPI-ESM1-2-LR은 기온 bias와 RMSE가 가장 작고 correlation도 높아 기온 재현성이 가장 우수한 모델로 나타났다.

반면 강수는 모든 CMIP6 모델에서 관측값보다 적게 모의되는 음의 bias가 나타났다. 특히 7월과 8월의 여름철 집중강수 시기에 음의 bias가 크게 나타나, 한국 강수 계절성 재현에 한계가 있음을 확인하였다.

강수 기준에서는 MPI-ESM1-2-HR이 상대적으로 가장 좋은 결과를 보였지만, correlation 자체는 높지 않았다. 따라서 고해상도 모델이 일부 강수 지표를 개선할 수는 있지만, 해상도 향상만으로 한국 여름철 강수 재현 문제가 완전히 해결되지는 않는다고 판단하였다.

## 7. 최종 결론

CMIP6 모델은 한국의 기온 계절성을 비교적 잘 재현한다. 그러나 강수, 특히 여름철 집중강수 재현성은 기온에 비해 낮다.

따라서 CMIP6 자료는 한국의 평균 기온과 계절 변화 분석에는 비교적 활용 가능성이 있지만, 강수 및 극한강수 분석에는 주의가 필요하다. 향후 연구에서는 더 많은 고해상도 모델을 추가하고, 관측자료 기반 보정 또는 downscaling 기법을 함께 적용할 필요가 있다.

## 9. Streamlit 대시보드 실행 방법

streamlit_app 폴더에서 다음 명령어를 실행하면 대시보드를 볼 수 있다.

cd streamlit_app
pip install -r requirements.txt
streamlit run app.py

## 10. 자료 관련 주의사항

ERA5, CMIP6, ASOS 원자료와 NetCDF 파일은 용량 문제와 재현성을 고려하여 저장소에 포함하지 않았다. 본 저장소에는 분석 코드, 핵심 결과표, 그림, 문서, 대시보드 파일만 포함한다.
